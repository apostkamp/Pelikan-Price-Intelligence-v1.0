# Pelikan-Price-Intelligence-v1.0
Pelikan Pricing &amp; Research Tool v1.0

## Startup
1. Άνοιξε το `index.html` με Chrome, Edge, Firefox ή Safari.
2. Επικόλληση μόνο URL ή κωδικό προϊόντος και ακολούθησε τα βήματα.

- Το ChatGPT κάνει την αναγνώριση από το URL/κωδικό.
- Εσύ επικολλάς την απάντηση και επιβεβαιώνεις την ταυτότητα.
- Μετά ετοιμάζεται η έρευνα αγοράς και στο τέλος καταχωρίζεις μόνο τη χονδρική.

## Σημαντικός περιορισμός
Αυτή είναι δωρεάν, στατική έκδοση χωρίς server ή API. 

Δεν μπορεί να διαβάζει αυτόματα ιστοσελίδες ούτε να εκτελεί μόνη της αναζητήσεις. 

Αντιγράφει τα κατάλληλα αιτήματα στο πρόχειρο και ανοίγει το ChatGPT· εσύ κάνεις επικόλληση και επιστρέφεις την απάντηση.
